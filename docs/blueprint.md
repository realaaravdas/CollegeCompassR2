# **App Name**: College Compass

## Core Features:

- Google Login & Drive Integration: Allow users to log in securely via Google and connect to Google Drive for data persistence.
- College Selection: Enable users to select colleges from a pre-populated list of both national and international institutions.
- College Info Retrieval & AI Augmentation: Utilize web scraping and a tool utilizing the Gemini API to populate college information, including images, deadlines, and application portals, being mindful of API usage limits. Prioritize user inputted API Key
- Score Input & Prediction: Enable users to input GPA and standardized test scores for estimated acceptance rate calculation.
- Major-Specific Acceptance Rate: Show an estimate of acceptance rate, specific to the department/major a user is applying for.
- Essay Tracking: Enable tracking of essays with a checklist format.
- Auto Save User Data: Automatic, server-side and/or Google Drive storage to preserve persistent app data.

## Style Guidelines:

- Primary color: Light pastel blue (#A8D0E6) to evoke feelings of trust, calmness, and hope.
- Background color: Off-white (#F0F4F8), to provide a clean and calming backdrop that prevents eye strain.
- Accent color: Muted teal (#77ACB4) for highlighting important deadlines and progress indicators.
- Headline font: 'Poppins' (sans-serif) for a modern, clean, and easily readable aesthetic.
- Body font: 'Inter' (sans-serif) for a neutral, unobtrusive reading experience.
- Use clear, minimalist icons sourced from a consistent set, like Material Design Icons, for intuitive navigation and visual clarity.
- A clean, organized layout that is easy to navigate on both desktop and mobile devices; prioritize a clear hierarchy of information.
